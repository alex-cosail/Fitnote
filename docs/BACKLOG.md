## v3: дорожная карта

Пользователи на площадке заинтересовались приложением — v3 делает его пригодным для других людей. ТЗ: [README_SPEC_INDEX.md](README_SPEC_INDEX.md). Архитектура: [ARCHITECTURE_V3_STEP0.md](ARCHITECTURE_V3_STEP0.md).

Ключевые решения (раздел 10–12 архитектуры): один профиль на телефон; **тренировки составляет движок на телефоне, без ИИ**; ИИ — через бриф в собственный ИИ-чат пользователя («Обсудить с ИИ») с необязательным обратным путём через валидатор движка; встроенный ИИ — позже и только при необходимости; лестница по семействам (болгарский −1 = приседания); для России — зеркало сайта на российском хостинге.

0. **Фундамент** (почти не виден пользователю): ~~тесты и вынос движка (0.1)~~ → ~~разделение плеера (0.2)~~ → ~~хранилище v2 с миграцией и резервной копией (0.3)~~ → каталог отдельно от данных → тренировка из слотов → роутер и каркас локализации.
1. **Каталог и генератор** — главная по объёму работа: 60–100 упражнений с разметкой (паттерн, семейство, ступень, среда, экипировка, `NO TOUCH`), шаблон разметки и проверка при сборке, правила генератора из раздела 1 брифа, кнопки −1 / +1 ступень на карточках и замена `⇄`, интерактивный «15+».
2. **Мастер старта:** 4 экрана с необязательным чек-апом, генератор недели, калибровка после первого круга, «Спасти неделю», предтренировочный редактор, «Отправить результаты и создать новую тренировку».
3. **Шеринг через QR** с адаптацией под получателя; «Обсудить с ИИ» (бриф со сводкой журнала) и «Вставить план от ИИ»; зеркало для России.
4. **Конструктор Workout Studio, «✨ Вариация», свои упражнения (YouTube, разметка в 3 клика), слайд-шоу разминки и анимированные SVG, интерфейс на RU / EN / TR.**
5. *По необходимости:* встроенный ИИ через прокси с адаптером провайдера.

Пункты «Надёжность месячного цикла» ниже частично закрываются шагом 0 (резервная копия, импорт) — сверить при планировании.

## Надёжность месячного цикла (найдено при разборе кода, не исправлено)

По приоритету для цикла «программа на месяц → журнал → тренер»:

1. **Экспорт для тренера обрезает данные до 20 записей** (`slice(0, 20)` в `SyncLogTab.buildCoachReport` для тренировок, кардио и чек-апов). Месячный журнал не помещается — тренер получает неполные данные.
2. ~~**Нет полной резервной копии и восстановления.**~~ *(Сделано в шаге 0.3: «Сохранить копию» / «Восстановить» на вкладке Sync / Log.)* Журнал живёт только в `localStorage`: очистка данных браузера, смена телефона или переустановка PWA стирают его.
3. **Прерванная тренировка не попадает в журнал.** В пошаговом режиме `roundsCompleted` всегда равен плану (в режиме «15+» уже честный).
4. **Импорт не проверяет JSON от ИИ.** Неизвестный `exerciseId` молча подменяется первым упражнением каталога (`?? exercises[0]` в плеере и на экране Workout). *(Сообщение «0 планов» при успешном импорте исправлено в шаге 0.1.)*
5. Экспорт за период: «с последнего чек-апа» или «за месяц», а не последние N записей.
6. Удаление записей журнала без подтверждения и без отмены.
7. Окно «Поставить на паузу и выйти?» паузу не ставит: таймер отдыха продолжает идти.
8. «Закрыть без сохранения» на финальном экране не удаляет незавершённую тренировку.

## Месячная программа (идея, обсудить)

- В приложении нет понятия «программа на месяц»: только список тренировок без расписания. Нужно: какая тренировка сегодня, сколько сделано из запланированных, основные и дополнительные занятия.
- Меняет формат JSON программы, а значит и промпт для ИИ в «Конструкторе запроса».

## Качество кода (техдолг)

- Неиспользуемые зависимости от шаблона AI Studio: `@google/genai`, `express`, `dotenv`, `motion`. Также `.env.example` с `GEMINI_API_KEY`, README AI Studio, имя пакета `react-example`.
- Нет тестов. Начать с чистых функций через Vitest: `calcAgt30`, `getWarmupPlan`, `findAntagonistMatches`, слияние при загрузке, нормализация импорта, перенос значений между кругами.
- Большие компоненты: `WorkoutPlayer.tsx` (около 1 900 строк) и `SyncLogTab.tsx` (около 1 150) — разнести фазы плеера по отдельным компонентам.
- Дублирование: `PROTECTED_WORKOUT_IDS` в двух файлах, `formatMetricTarget` = `formatMetricShort`, таймер «5 с → секундомер» в Check-Up и в плеере, сотни повторяющихся классов тёмной темы.
- Главный тикер плеера пересоздаёт интервал на каждом рендере (`useEffect` без зависимостей), у эффекта баннера раунда неполные зависимости.
- `loadFitnoteData()` вызывается при старте дважды; версия схемы `_v1` без миграций; ошибки переполнения `localStorage` глотаются молча.
- Номер шага разминки и упражнения собирается как `0{n}`: при 10 и больше будет «010».
