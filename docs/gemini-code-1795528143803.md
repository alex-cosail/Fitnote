# Дополнение №4 к SPEC_FITNOTE_V3.md
**Тема:** Трёхъязычная локализация интерфейса и каталога упражнений (`RU` / `EN` / `TR`) с привязкой к профилю пользователя.

---

## 1. Цель
Обеспечить мгновенное переключение языка интерфейса и базы упражнений между русским (`ru`), английским (`en`) и турецким (`tr`) без перезагрузки страницы, чтобы одним устройством или ссылкой могли свободно пользоваться люди на уличной площадке в Турции.

---

## 2. Архитектурные требования
1. **Словари интерфейса (`src/i18n/`):**
   - Вынести все строки UI (онбординг, конструктор, плеер, разминка/заминка, системные уведомления) в типизированные словари `ru.ts`, `en.ts`, `tr.ts` с единым ключом перевода `t(key)`.
   - Добавить компактный переключатель языка (`RU / EN / TR`) в шапку приложения и в настройки профиля.
2. **Привязка языка к профилю (`UserProfile`):**
   - Добавить поле `locale: 'ru' | 'en' | 'tr'` в модель `UserProfile`. При смене активного профиля язык интерфейса переключается автоматически; при первом запуске язык определяется по настройкам браузера (`navigator.language`) с фолбэком на `en`.
3. **Локализация каталога (`Exercise`) и безопасный фолбэк:**
   - Хранить `name` и `cue` (подсказку по технике) в базовом каталоге в виде структуры `{ ru: string; en: string; tr: string }` с корректной турецкой спортивной терминологией (*Barfiks*, *Şınav*, *Paralel Bar Dips*, *Plank* и т.д.).
   - Для пользовательских упражнений (`isCustom: true`, добавленных вручную или с YouTube) разрешить заполнение только одного языка с автоматическим фолбэком отображения при переключении локали.
4. **Локализация промпта для ИИ (`aiBriefBuilder.ts`):**
   - Генератор брифа для внешнего ИИ формирует текстовую часть запроса на языке активной локали (`ru` / `en` / `tr`), сохраняя системные ключи JSON-схемы неизменными для корректного обратного импорта.
