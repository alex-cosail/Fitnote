# Fitnote — что сделано

Журнал наработок проекта. Планы и открытые вопросы — в [BACKLOG.md](BACKLOG.md).

## Назначение

Fitnote — офлайн-блокнот и линейный плеер функциональных тренировок на площадке и дома.

Месячный цикл:

1. Чек-ап (замеры максимумов) в приложении.
2. Тренер или ИИ по чек-апу и журналу составляет программу на месяц: 3 тренировки в неделю плюс дополнительные при необходимости. Программа приходит в виде JSON и импортируется.
3. На площадке упражнения идут одно за другим, фиксируются только фактические значения. Каждая тренировка попадает в журнал.
4. В конце месяца журнал уходит тренеру или ИИ, затем новый чек-ап и новая программа.

Главное требование: **приложение полностью работает без интернета.** На площадке сети нет никогда. Общение с тренером и ИИ (экспорт и импорт JSON) — дома вечером.

## Стек и устройство

- React 19 + TypeScript + Vite 8 + Tailwind CSS v4, PWA (`vite-plugin-pwa`, Workbox).
- Все данные хранятся в `localStorage` под ключом `fitnote_store` в конверте с версией схемы (сейчас 3) и цепочкой миграций (`src/storage/schema.ts`). Старый ключ `fitnote_offline_store_v1` (до v2.1) не удаляется — страховка.
- Звуки синтезируются через Web Audio API (`src/utils/audio.ts`), аудиофайлов нет.
- Экран не гаснет во время тренировки (Wake Lock, `src/hooks/useWakeLock.ts`).
- Ключевые файлы:
  - `src/types.ts` — модель данных;
  - `src/App.tsx` — корневое состояние, старт сессии, вкладки по адресу;
  - `src/domain/` — движок без интерфейса (каталог, лестница, условия, подбор слотов, цели, переходы плеера) с тестами;
  - `src/components/WorkoutPreviewTab.tsx` — экран выбора и настройки тренировки;
  - `src/components/WorkoutPlayer.tsx` и `src/components/player/` — плеер по фазам, хуки таймеров;
  - `src/data/catalog.ts`, `src/data/catalogText.ru.ts` — каталог упражнений и тексты;
  - `src/data/seed.ts` — стартовые планы, разминка, заминка;
  - `src/storage/` — схема, миграции, резервная копия;
  - `src/routing/`, `src/i18n/` — адреса экранов, перевод.
- Команды: `npm test` (Vitest), `npm run lint` (типы), `npm run build`, `npm run catalog:check -- файл.json` (проверка новых упражнений).

## Релизы и деплой

- `main` — рабочая ветка, `release` — деплой. Cloudflare Pages собирает сайт из `release`.
- Номер версии — поле `version` в `package.json`. При сборке он попадает в приложение и показывается мелко рядом с логотипом: `3.0.0` → «v.3», `3.1.0` → «v.3.1».
- Выпуск релиза:
  1. Поднять `version` в `package.json`, закоммитить в `main`.
  2. Отправить в релиз: `git push origin main:release`.
  3. Поставить на этот коммит тег с тем же номером (`git tag -a v3 …`) и запушить тег.
- Обновление на телефоне: открыть приложение с интернетом, закрыть и открыть снова. Офлайн-кэш обновится сам.
- Локальная проверка: `npm install`, `npm run build`, `npm run preview` (офлайн-кэш включается только по HTTPS или на `localhost`).

## v2 — плеер и экран тренировки

ТЗ: [gemini-code-1795184808916.md](gemini-code-1795184808916.md), с уточнениями заказчика.

### Офлайн
- Шрифты (Plus Jakarta Sans, Barlow Condensed, JetBrains Mono) встроены через `@fontsource` и входят в офлайн-кэш. Запросов к Google Fonts нет.
- В сборке нет внешних адресов, офлайн-кэш содержит всё приложение (41 файл).

### Экран Workout: настройка перед тренировкой
- Кнопки `−`/`+` для числа кругов (1–20) и для цели каждого упражнения (повторения шагом 1, секунды шагом 5). Изменения сразу сохраняются.
- Кнопка «План тренера» возвращает исходные цифры (снимок хранится в `WorkoutPlan.original`). Повторный импорт плана от тренера заменяет правки.
- Не показываются при красном самочувствии и в планах AGT 30%.

### Плеер
- **Кольцо прогресса** в шапке: номер круга и доля пройденных упражнений круга.
- **Упражнения на повторения:** крупная картинка на свободном месте; три столбика одинаковой высоты `−` | число | `+`. Тап по числу сохраняет подход (короткая зелёная подсветка «Записано»), кнопки «Готово» нет. У парных упражнений первый тап — левая сторона (красное число), второй — правая (зелёное). RIR выбирается до тапа. В ландшафте число растёт со свободным местом.
- **Упражнения на время (автопилот):** после отдыха сам стартует отсчёт 5 с, затем таймер идёт до цели, сам останавливается и включает отдых. У парных — автоматический переворот 7 с и вторая сторона. Тап по таймеру — пауза или продолжение, двойной тап — заново с 5 с готовности. Таймер на всю ширину зоны, под ним подсказка и одна кнопка «Левая сторона» / «Правая сторона» / «Готово» для досрочного завершения. Кнопок `−`/`+` и выбора RIR нет.
- **Перенос значений между кругами:** следующий круг открывается с фактическим результатом предыдущего. Для упражнений на время только вверх, чтобы досрочная или случайная остановка не срезала цель. Изменение действует только внутри текущей тренировки. В журнале сохраняется исходная цель тренера (`SetLog.plannedTarget`).
- **Отдых:** весь экран бирюзовый, включая фон картинки, таймера и кнопки звука, чтобы отдых не путался с работой. Картинка следующего упражнения крупная, таймер на всю ширину, кнопки «+15 сек» и «Пропустить» под ним. За 3 секунды до конца цифры краснеют.
- **Режим «15+»** (планы AGT или от 8 кругов, кроме красного самочувствия): все упражнения круга на одном экране, счётчик «Кругов выполнено», цель «N+» без потолка. Кнопка «+1 круг выполнен» записывает весь круг (факт = цель, RIR `2+`) и запускает отдых между кругами. «Закончить → Заминка» доступна после первого круга. В журнал пишется реальное число кругов. Отдыха между упражнениями внутри круга в этом режиме нет — по ТЗ.

### Модель данных (обратно совместимо)
Добавлены только необязательные поля, старые данные читаются как раньше:
- `WorkoutPlan.original` — снимок плана тренера для сброса;
- `ActiveSession.items[].plannedTarget`, `SetLog.plannedTarget` — исходная цель;
- `ActiveSession.isRoundFlow` — режим «15+».

### Ключевые решения v3 (сессия 24.11.2026)

Подробно — разделы 10–12 [ARCHITECTURE_V3_STEP0.md](ARCHITECTURE_V3_STEP0.md).

- У каждого свой телефон: один профиль на устройство, без переключателя.
- Шеринг тренировкой или циклом, без подписи автора; чек-ап необязателен, цифры уточняются калибровкой после первого круга.
- **Тренировки составляет движок на телефоне, без ИИ** (офлайн, бесплатно, одинаково в любой стране). ИИ — через бриф «Обсудить с ИИ» в собственный ИИ-чат пользователя, обратный путь «Вставить план от ИИ» — через проверку движком. Встроенный ИИ (прокси на Cloudflare Workers или YandexGPT / GigaChat для России) — только при необходимости.
- Лестница строится по семействам (болгарский −1 = приседания), кнопки −1 / +1 прямо на карточке.
- Для России — зеркало сайта на российском хостинге; Claude для пользователей из России не используется.
- Импорт и экспорт без «подноготной»: пользователь видит намерения, а не JSON.
