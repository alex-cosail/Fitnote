# Архитектура AI-сервиса и монетизация Fitnote

Документ описывает гибридную модель взаимодействия пользователя с нейросетью (бесплатный ручной режим + платный режим «в один клик») для масштабирования приложения без убытков на API-токенах.

---

## 1. Проблема и экономика
При классической интеграции AI-чата или Telegram-бота все запросы идут через единый API-ключ разработчика. При росте аудитории расходы на токены ложатся на владельца приложения.

**Решение:** Двухрежимная архитектура, которая разделяет аудиторию по её готовности платить или тратить 30 секунд на ручной перенос данных.

### Ожидаемое распределение аудитории (на 1 000 пользователей)
* **70–75% (отсев):** Массовые пользователи, не готовые ни платить, ни разбираться с буфером обмена.
* **20–25% (бесплатное ядро):** Энтузиасты, гики, уличные атлеты. Используют свои лимиты в личных чатах (Gemini / ChatGPT) через копипаст. Расходы разработчика = **0 €**.
* **2–5% (платные подписчики):** Посетители тренажёрных залов и занятые пользователи. Покупают подписку за **€3 / мес (~300 ₽)** ради бесшовной работы в один клик. Себестоимость API-запросов на одного такого пользователя составляет несколько центов в месяц.

## 2. UX-развилка: две кнопки на экране генерации

### Правило первого касания (Hook)
Нельзя показывать экран оплаты до первой демонстрации ценности.
1. При первом запуске или после первого чекапа пользователь получает **1–2 бесплатные генерации в один клик** (через серверный ключ разработчика).
2. Начиная со 2–3-й генерации или при запросе на адаптацию цикла по отчёту появляется развилка выбора режима.

### Визуальная иерархия кнопок
* **Основная кнопка (акцентная):**
  * **Текст:** `Собрать план в 1 клик · €3 / мес` (или `Персональный тренер · 300 ₽/мес`).
  * **Подпись:** *«ИИ сам проанализирует ваши веса и максимумы и сразу загрузит программу в блокнот».*
* **Вторая кнопка (спокойная / контурная):**
  * **Текст:** `Бесплатно · Через свой чат (Gemini / ChatGPT)`
  * **Механика:** Открывает компактное модальное окно из 3 шагов:
    1. Кнопка **«1. Скопировать запрос»** (системный промпт + актуальный JSON пользователя уже сформированы).
    2. Ссылка **«2. Открыть свой чат с ИИ»**.
    3. Поле **«3. Вставить ответ»** + кнопка **«Импортировать»**.

## 3. Что получает пользователь «под капотом» в платном режиме (€3/мес)

При оплате подписки запросы идут через серверный обработчик (например, **Cloudflare Worker**) напрямую в Gemini API:

1. **Гарантия валидного формата (Structured Outputs):** API настраивается на строгую JSON-схему приложения. Модель физически не может вернуть текст с опечатками, сломанными кавычками или лишними комментариями.
2. **Автоматический контекст:** Скрипт сам подтягивает историю тренировок, актуальные `checkUpMaxes` / рабочие веса и выбранный инвентарь пользователя.
3. **Замена упражнений «на лету»:** Прямо во время тренировки в зале (если тренажёр занят) пользователь нажимает одну кнопку и за 3 секунды получает замену в рамках того же паттерна движения.

## 4. Опционально: Telegram-бот как компаньон
* **Без регистрации:** Авторизация происходит автоматически по `user_id` в Telegram при нажатии `/start`.
* **Связка с Cloudflare:** Бот на Cloudflare Workers может использовать общую базу (KV / D1) с веб-приложением.
* **Роль в продукте:** Может служить удобным каналом для приёма голосовых и текстовых отчётов после тренировки с автоматическим обновлением весов и планов в основном приложении (как часть платного тарифа).
