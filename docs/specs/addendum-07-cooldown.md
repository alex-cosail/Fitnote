# Дополнение №7 к SPEC_FITNOTE_V3.md
**Тема:** Потоковая заминка (`Cooldown Flow · 4:30`) — автозапуск после тренировки, дыхательный ритм `4–6` и статическая растяжка стоя (`NO TOUCH`).

---

## 1. Архитектурное решение
Чтобы заминка не игнорировалась пользователем после завершения основного блока, в финальный экран активной тренировки встраивается переход к единому потоковому комплексу **`Cooldown · Восстановление (270 сек / 4 мин 30 сек)`**.

Ключевые принципы комплекса:
1. **100% `NO TOUCH` (стоя у стойки или скамьи):** все 7 позиций выполняются без опускания на землю или коврик, с опорой рукой для стабильности и расслабления мышц-стабилизаторов.
2. **Охват главных мышечных цепей:** дыхательная перезагрузка → грудные/передние дельты → широчайшие/грудной отдел → задняя поверхность бедра → ягодичные/грушевидная → передняя поверхность бедра/сгибатели таза → икроножные/ахилл.

---

## 2. Требования к плееру заминки (`CooldownPlayer`)
1. **Сценарий завершения основной тренировки:**
   - По окончании последнего круга основной сессии первичной CTA-кнопкой становится **`Завершить с заминкой (4:30)`**, а действие **`Завершить без заминки`** выносится в спокойную текстовую ссылку ниже.
2. **Потоковый режим (`autoAdvance: true`) и смена стороны (`splitCueAt`):**
   - Упражнения идут последовательно без пауз (`restBetweenExercises: 0`).
   - Для односторонних растяжек (шаги 2, 4, 5, 6, 7) срабатывает мягкий звуковой/вибро-сигнал смены стороны на отметке `splitCueAt` (`15`, `20` или `25` секунда).
3. **Визуальный метроном дыхания (`breathingPace: "4-6"`):**
   - На экране таймера заминки отображается плавный индикатор дыхательного цикла: **4 секунды плавный вдох** → **6 секунд длинный выдох** (активация парасимпатической нервной системы для снижения ЧСС и мышечного тонуса).
4. **Подсветка целевых зон прошедшей тренировки (`highlightZones`):**
   - Если в завершённой тренировке присутствовали тяги (`pull_v` / `pull_h`), плеер визуально подсвечивает шаг №3 (`cd-lat-thoracic-hang`); если были приседания или выпады (`squat` / `lunge` / `hinge`) — подсвечивает шаги №4–6.
