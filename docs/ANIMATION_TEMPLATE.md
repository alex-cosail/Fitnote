# Fitnote — шаблон анимированных картинок упражнений

Как вместе с ИИ сделать анимированную картинку упражнения в стиле нынешних картинок Fitnote. Подход — из ТЗ [svg_fitnote.md](svg_fitnote.md) (раздел 3): покадровая смена поз в SVG с CSS-анимацией, без GIF и видео, 1,5–3 КБ на упражнение. Упражнения размечаются отдельно — [CATALOG_TEMPLATE.md](CATALOG_TEMPLATE.md).

## Как это работает

1. Даёте ИИ промпт из раздела «Промпт для ИИ» и список id упражнений с названиями (например, из файла партии каталога).
2. ИИ возвращает по одному SVG на упражнение. Каждый сохраняете в `docs/catalog/motion/<id>.svg`, например `docs/catalog/motion/air-squats.svg`.
3. Открываете файл в браузере (двойной клик). Проверяете по списку из раздела «Проверка». Замечания отправляете обратно в ИИ.
4. Отдаёте файлы мне: я подключаю их в приложение. Упражнение без анимации показывает нынешнюю статичную картинку.

Образец — [catalog/example-air-squats.svg](catalog/example-air-squats.svg): воздушные приседания, 4 кадра (стойка → полуприсед → низ → полуприсед), 1,9 КБ.

## Стиль (как у нынешних картинок)

| Что | Значение |
|---|---|
| Поле | `viewBox="0 0 160 120"`, без `width` и `height` |
| Фигура | линии, без заливок: чёрный `#111827`; голова — окружность r 7, толщина 2,8; корпус — 3,5; руки и ноги — 3; концы и углы скруглены |
| Акцент | красный `#DC2626`: работающий сегмент тела (например, бедро в приседе) и стрелка движения |
| Снаряды | турник и брусья — `#111827`, толщина 3,5; стойки — `#D1D5DB`; земля — линия `#E5E7EB` на y = 110 |
| Пропорции (единицы поля) | голова r 7, шея 2, корпус 34, бедро 20, голень 18, плечо 16, предплечье 14, стопа 12. **Длины сегментов одинаковы во всех кадрах** — меняются только углы |
| Вид | сбоку, лицом вправо; парные упражнения — рабочая сторона, вторую приложение отзеркалит |
| Без | текста, градиентов, теней, фильтров, скриптов, внешних ссылок и картинок |

## Анимация

- **Кадры** — 2–4 позы в порядке показа, включая возврат: стойка → середина → низ → середина. Повторяющуюся позу не рисуют второй раз, а ссылаются на неё через `<use>`.
- Каждая поза — `<g class="fr fN">`; самая показательная (обычно нижняя точка) дополнительно получает класс `key`.
- Цикл **2,4 с**, кадры сменяются резко (`steps(1,end)`): 4 кадра по 0,6 с, 3 кадра по 0,8 с, 2 кадра по 1,2 с.
- Кадр N получает `animation-delay: −(кадров − N) × длительность кадра` (кадр 0 — без задержки). Так кадры идут по очереди на одной общей анимации.
- **Упражнения на удержание** (планка, вис): одна поза с классом `key` без `fr`, а красный акцент мягко «дышит»: прозрачность 0,4 ↔ 1 за 2 с.
- **Ротация и махи** (разминка): вместо кадров — вращение сегмента вокруг сустава (`transform-origin` в точке сустава) и пунктирная красная дуга со стрелкой.
- **Без анимации** (`prefers-reduced-motion`): показывается кадр `key` и стрелка движения.
- Все классы и имя анимации начинаются с `fx-<id>`, чтобы несколько картинок на одном экране не мешали друг другу.

## Проверка

- [ ] Файл открывается в браузере, фигура двигается плавно по кругу, без «прыжков» сегментов.
- [ ] Длины рук, ног и корпуса не меняются от кадра к кадру.
- [ ] Видна суть упражнения: где опора, куда движение, что работает (красным).
- [ ] Ничего не выходит за поле 160 × 120.
- [ ] Размер файла не больше 3 КБ.
- [ ] Все классы начинаются с `fx-<id>`; у одной позы есть класс `key`.

## Промпт для ИИ

Скопируйте целиком, в конце допишите список упражнений:

````text
Ты рисуешь анимированные картинки упражнений для приложения Fitnote — офлайн-тренера
для уличной площадки и дома. Картинка смотрится на телефоне на солнце, поэтому стиль
строгий: тонкая фигурка из линий, чёрный и один красный акцент.

Верни для каждого упражнения строку "id: <id>" и под ней ОДИН блок кода с SVG.
Без пояснений.

СТИЛЬ
- <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 160 120" class="fx-<id>">,
  без width и height.
- Фигура — только линии, без заливок: stroke="#111827", stroke-linecap="round",
  stroke-linejoin="round", fill="none". Голова — circle r="7" stroke-width="2.8";
  корпус — stroke-width="3.5"; руки, ноги, стопа — stroke-width="3".
- Пропорции в единицах поля, ОДИНАКОВЫЕ ВО ВСЕХ КАДРАХ (меняются только углы):
  голова r 7, шея 2, корпус 34, бедро 20, голень 18, плечо 16, предплечье 14, стопа 12.
  Рост стоящей фигуры ≈ 90; стопы на y = 108.
- Земля: <line x1="20" y1="110" x2="140" y2="110" stroke="#E5E7EB" stroke-width="2"/>.
- Снаряды: перекладина и брусья — #111827, stroke-width 3.5; стойки — #D1D5DB.
- Красный #DC2626 — только две вещи: работающий сегмент тела (перекрась его линию)
  и стрелка направления движения (stroke-width 2.2) сбоку от фигуры.
- Вид сбоку, лицом вправо. Парное упражнение — рисуй правую рабочую сторону.
- Нельзя: текст, градиенты, тени, фильтры, script, внешние ссылки и картинки.
- Координаты — целые или с одним знаком после запятой. Размер файла ≤ 3 КБ.

АНИМАЦИЯ
- 2–4 ключевые позы в порядке показа, включая возврат (стойка → середина → низ →
  середина). Повтор позы — через <use href="#fx-<id>-имя">, а не копией: обёртку
  позы с id делай внутренней <g id="..."> без классов.
- Каждая поза — <g class="fr fN">, N = 0, 1, 2, 3. Самая показательная поза
  (обычно нижняя точка) получает ещё класс key.
- Цикл 2.4s, смена резкая. Для N кадров длительность кадра D = 2.4 / N секунд;
  кадр k получает animation-delay: -((N - k) mod N) × D. Ключевой кадр анимации:
  видим первые 100/N % цикла.
- Удержание (планка, вис): одна поза с классом key без fr; красный акцент «дышит»:
  @keyframes opacity 0.4 → 1 → 0.4 за 2s ease-in-out infinite.
- Ротация и махи (разминка): вращение сегмента вокруг сустава (transform-origin
  в точке сустава, rotate туда-обратно) и пунктирная красная дуга со стрелкой.
- prefers-reduced-motion: анимации выключены, виден кадр key и стрелка.
- Все классы и имя @keyframes начинаются с fx-<id>.
````
