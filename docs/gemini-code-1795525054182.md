## Задача 1. Интерактивный режим `15+ кругов` в плеере (`WorkoutPlayer.tsx`)

### Проблема
Сейчас в режиме `15+ кругов` нажатие кнопки `+1 КРУГ` записывает в лог статичные цели из исходного плана. На практике в длинных сессиях (15–20 кругов) спортсмен может в середине тренировки поднять целевые повторения (например, брусья с `5` до `7`) или заменить уставшее упражнение на более лёгкое по лестнице (например, `Bulgarian Split Squat` → `Air Squats`, или `Side Plank` → `Hanging Oblique Leg Raises`).

### Требования к реализации
1. В сетке `2×2` режима `15+ кругов` сделать каждую карточку упражнения интерактивной:
   - Добавить компактные кнопки **`−`** и **`+`** рядом с цифрой цели внутри карточки, чтобы на лету менять рабочую цель упражнения для текущего и всех последующих кругов.
   - Добавить кнопку **`⇄` (Замена)** в угол карточки упражнения.
2. По нажатию `⇄` открывать компактное модальное окно выбора замены из лестницы прогрессий (`ladder`) или того же паттерна движения (`pattern`) с автоматическим пересчётом цели пропорционально `checkup_max`:
   `newTarget = Math.max(1, Math.round(currentTarget * (nextEx.checkup_max / currentEx.checkup_max)))`.
3. Кнопка `+1 КРУГ` записывает в `SetLog` актуальное состояние карточек на момент нажатия (включая `swappedFromName`, если упражнение было заменено по ходу сессии).
