## Задача 5 (Дополнение к SPEC_CATALOG_V2.md). Контекстная фильтрация альтернатив по среде и инвентарю

### Цель
При выборе замены упражнения (в каталоге или во время тренировки в модальном окне замены) пользователь должен иметь возможность указать текущие условия (**Локация**: `Площадка` / `Дом` и **Инвентарь**: `Турник и брусья`, `Петли`, `Резинки`, `Свободные веса / утяжелители`, `Без инвентаря`), чтобы система мгновенно отфильтровывала недоступные варианты и показывала только те упражнения из лестницы прогрессий, которые можно выполнить прямо сейчас.
