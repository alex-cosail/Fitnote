# Дополнение №2 к SPEC_FITNOTE_V3.md и SPEC_FITNOTE_ONBOARDING_WIZARD.md
**Тема:** Переход после настройки профиля на экран «Воркауты» и предтренировочная ручная корректировка плана перед запуском.

---

## 1. Маршрут после завершения мастера старта (Onboarding → Workouts)
1. По нажатию кнопки **«Сформировать программу»** на 4-м экране мастера старта пользователь автоматически перенаправляется на основной экран **`Воркауты` (Workouts)**, где его уже ждёт сформированный набор тренировок (например, `День A`, `День B`, `День C` или одиночный комплекс `Full-Body Reset`) + карточка быстрой **5-минутной разминки**.
2. В шапке экрана отображается компактный бейдж активного профиля и текущих условий (например: `Алексей · Сила 80% · 45 мин · Турник/Брусья · NO TOUCH`) с возможностью в 1 клик открыть мастер заново и пересобрать цикл.

---

## 2. Предтренировочный редактор на экране выбора воркаута (Pre-Workout Tuner)
При открытии карточки выбранного воркаута (до нажатия кнопки **«Начать тренировку»**) пользователь видит список упражнений и может внести точечные правки под текущее самочувствие:

1. **Замена упражнения на соседа по лестнице (`⇄`):**
   * Рядом с каждым упражнением в списке доступна кнопка замены `⇄`.
   * По нажатию открывается выбор альтернатив из того же паттерна движения (`pattern`) — с облегчением (`Старт` / `База`) или усложнением (`Прогресс` / `Мастер` / с резинкой / с весом), отфильтрованный под доступную экипировку и флаг `NO TOUCH`.
   * Целевое число повторений пересчитывается автоматически пропорционально `checkup_max`, но остаётся открытым для ручной правки.
2. **Корректировка повторений и числа кругов (`−` / `+`):**
   * Напротив каждого упражнения — кнопки **`−`** и **`+`** для ручной корректировки целевых повторений (или секунд для статики/виса).
   * В верхней панели карточки воркаута — переключатель **числа кругов (`Rounds: − / +`)**, позволяющий уменьшить или увеличить общий объём сессии перед стартом.
3. **Режим применения правок при запуске («Старт»):**
   * Нажатие **«Начать тренировку»** запускает `WorkoutPlayer` с актуальным отредактированным составом.
   * При изменении состава упражнения или кругов появляется ненавязчивая опция **`Сохранить как шаблон`** (если галочка не стоит — правка действует разово на текущую сессию, не ломая базовый шаблон цикла).
