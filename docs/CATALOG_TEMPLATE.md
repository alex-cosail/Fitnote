# Fitnote — шаблон разметки упражнений для каталога

Инструкция для шага 1: как вместе с ИИ подготовить новые упражнения так, чтобы они сразу встали в каталог, участвовали в генераторе, лестнице `-- … ++` и фильтрах условий.

## Как это работает

1. Вы даёте ИИ промпт из раздела «Промпт для ИИ» и список упражнений, которые хотите добавить (или просите ИИ закрыть пробелы из раздела «Что нужно покрыть»).
2. ИИ возвращает JSON-файл в формате из раздела «Формат файла». Сохраните его в `docs/catalog/`, например `docs/catalog/batch-01.json`.
3. Проверьте файл:

   ```bash
   npm run catalog:check -- docs/catalog/batch-01.json
   ```

   Скрипт на русском перечислит ошибки (✗) и предупреждения (!) и покажет таблицу покрытия: сколько упражнений на каждую ступень в каждом паттерне, на площадке и дома. Ошибки отправляйте обратно ИИ, пока их не останется.
4. Отдайте файл мне: я переношу упражнения в `src/data/catalog.ts` и тексты в `catalogText.*.ts`. Тесты проверят разметку ещё раз при каждой сборке.

Образец файла — [catalog/example-new-exercises.json](catalog/example-new-exercises.json) (воздушные приседания и отжимания от опоры, проходит проверку без ошибок).

## Формат файла

```json
{
  "exercises": [
    {
      "id": "air-squats",
      "pattern": "squat",
      "family": "legs_knee",
      "rank": 2,
      "metric": "reps",
      "isPaired": false,
      "environments": ["outdoor", "home"],
      "equipment": ["bodyweight"],
      "posture": ["standing"],
      "stability": "bilateral",
      "targetMuscles": ["quads", "glutes"],
      "antagonistMuscles": ["hamstrings"],
      "svgKey": "generic_strength",
      "defaultMax": { "low": 10, "medium": 25, "high": 50 },
      "teenAllowed": true,
      "ladder": { "minus1": "…", "plus1": "reverse-lunges" },
      "text": {
        "ru": { "name": "Air Squats", "cue": "…", "details": "…" },
        "en": { "name": "Air Squats", "cue": "…", "details": "…" },
        "tr": { "name": "Hava Squat", "cue": "…", "details": "…" }
      }
    }
  ]
}
```

## Поля

| Поле | Обязательно | Значения | Смысл |
|---|---|---|---|
| `id` | да | латиница в нижнем регистре, цифры, дефисы: `air-squats` | Постоянный идентификатор. Никогда не меняется и не переиспользуется. Если упражнение уже есть у вас как «своё» (пришло от тренера), используйте **тот же id** — см. ниже |
| `pattern` | да | `push_h`, `pull_h`, `push_v`, `pull_v`, `squat`, `hinge`, `lunge`, `core` | Один из 8 паттернов движения (раздел 1.1 брифа v3) |
| `family` | да | см. «Семейства» | Семейство лестницы: внутри него работают кнопки −1 / +1. Может объединять паттерны (присед и выпады — `legs_knee`) |
| `rank` | да | 1–5 | Ступень: 1 `--`, 2 `-`, 3 `Base`, 4 `+`, 5 `++` (см. «Опорные ступени») |
| `metric` | да | `reps`, `seconds` | Повторения или удержание на время |
| `isPaired` | нет | `true` | Выполняется на каждую сторону (выпады, боковая планка) — плеер ведёт левую и правую стороны |
| `environments` | да | `outdoor`, `home` | Где можно выполнить |
| `equipment` | да | `bodyweight`, `pullup_bars`, `suspension`, `bands`, `weights` | Что нужно (достаточно любого из списка). `bodyweight` = ничего не нужно |
| `posture` | да | `standing`, `hands_only`, `floor_contact` | Контакт с поверхностью. `floor_contact` (локти, спина, колени на земле) исключается в режиме `NO TOUCH` |
| `stability` | да | `bilateral`, `unilateral`, `unstable` | Для квоты баланса: одноопорное или нестабильное |
| `targetMuscles` | да | теги мышц (см. ниже) | Работающие мышцы |
| `antagonistMuscles` | да | теги мышц, можно `[]` | Мышцы-антагонисты — для замены на антагониста и чередования в круге |
| `svgKey` | да | см. ниже | Картинка. Если подходящей нет — `generic_strength` |
| `defaultMax` | да | `{low, medium, high}`, числа > 0, low ≤ medium ≤ high | Стартовый максимум без чек-апа для «Начинающий / Средний / Продвинутый». Для `seconds` — в секундах |
| `teenAllowed` | нет | `false` | Запретить для подростков (кроме ступени 5, которая запрещена для них всегда) |
| `ladder.minus1` / `ladder.plus1` | нет | id из каталога или из этого же файла, того же `family` | Предпочтительный сосед на ступень легче / тяжелее. Важнее вычисленного по семейству |
| `text.ru` | да | `name`, `cue`, `details` | Название, подсказка (одно предложение до 140 символов, читается на площадке), описание техники (3–5 предложений) |
| `text.en`, `text.tr` | нет | то же | Английский и турецкий; при отсутствии показывается русский |

**Свои упражнения, которые переходят в каталог.** Сейчас у вас есть три своих упражнения от тренера: `air-squats` (Air Squats), `single-leg-rdl` (Single-Leg Romanian Deadlift), `hanging-knee-raises` (Hanging Knee Raises). Если добавлять их в каталог, берите именно эти id. После обновления приложения своё упражнение с таким id само станет упражнением каталога: ваш максимум сохранится, планы и журнал продолжат на него ссылаться, дубля не будет.

**Теги мышц:** `lats`, `biceps`, `chest`, `triceps`, `front_delts`, `rear_delts`, `upper_back`, `quads`, `glutes`, `hamstrings`, `hip_flexors`, `obliques`, `core`, `lower_back`, `forearms`, `spine_decompression`, `shoulder_press`. Новый тег допустим, но проверка предупредит: для него нужно русское название в `src/domain/catalog/muscles.ts`.

**Картинки (`svgKey`):** `pullups`, `dips`, `australian_pullups`, `pushups`, `bulgarian_split_squat`, `glute_bridge`, `side_plank`, `dead_hang`, `pallof_press`, `romanian_deadlift`, `band_row`, `reverse_lunges`, `pike_pushups`, `generic_strength`. Можно взять похожую (отжимания от опоры — `pushups`). Анимированные картинки делаются отдельным промптом — [ANIMATION_TEMPLATE.md](ANIMATION_TEMPLATE.md).

## Опорные ступени

Ранги ставятся относительно упражнений, которые уже есть (Base = 3):

| Семейство | 1 `--` | 2 `-` | 3 `Base` | 4 `+` | 5 `++` |
|---|---|---|---|---|---|
| `push_horizontal` | | отжимания от опоры | Floor Push-Ups | Parallel Bar Dips | |
| `pull_horizontal` | | Band Row | Australian Pull-Ups | | |
| `pull_vertical` | | | Strict Pull-Ups | | |
| `push_vertical` | | | Pike Push-Ups | | |
| `legs_knee` | | воздушные приседания | Reverse Lunges | Bulgarian Split Squat | |
| `hinge` | | Single-Leg Glute Bridge | Romanian Deadlift | | |
| `core_lateral` | | | Side Plank | | |
| `core_antirotation` | | | Pallof Press | | |
| `hang` | | Dead Hang | | | |

Правило: соседние ступени отличаются заметно (примерно в полтора раза меньше повторений при том же усилии), а 5 `++` — уровень продвинутого атлета.

## Семейства

Существующие: `push_horizontal`, `push_vertical`, `pull_horizontal`, `pull_vertical`, `legs_knee`, `hinge`, `core_lateral`, `core_antirotation`, `hang`.

Новое семейство заводите, только если упражнения не заменяют друг друга по лестнице (например `core_antiextension` для планки на прямых руках, «мёртвого жука» и ролика). Имя — латиница через подчёркивание.

## Фильтр безопасности

В каталог не попадают упражнения с высоким риском для суставов: отжимания на брусьях за спиной (от скамьи), тяги и жимы за голову, «кипинг»-подтягивания, прыжковые упражнения с жёстким приземлением для уровня `low`, скручивания с нагрузкой на шею. Для подростков ступень 5 недоступна автоматически; `teenAllowed: false` — для упражнений с высокой осевой нагрузкой на ступенях ниже.

## Что нужно покрыть

Цель — 3–5 упражнений на каждый паттерн в каждой среде, по разным ступеням, чтобы ротация «не скучно» и замена по лестнице работали везде. Таблицу текущего покрытия показывает `npm run catalog:check`. Ориентировочный список (без опасных упражнений):

| Паттерн | Кандидаты |
|---|---|
| `push_h` | отжимания от колен (1), отжимания от опоры (2), отжимания в петлях (4), отжимания «лучник» (5) |
| `pull_h` | австралийские с ногами на возвышении (4), тяга в петлях (3), тяга одной рукой в петлях (5) |
| `push_v` | жим резинки вверх (2), отжимания «домиком» с ногами на возвышении (4), стойка у стены (5, на время) |
| `pull_v` | подтягивания лопатками (1), негативные подтягивания (2), подтягивания с резинкой (2), подтягивания обратным хватом (3), подтягивания «лучник» (5) |
| `squat` | присед на ящик (1), воздушные приседания (2), гоблет-присед (3, вес), казачий присед (4), «пистолет» на возвышение (5) |
| `hinge` | ягодичный мост на двух ногах (1), «гуд морнинг» с резинкой (2), румынская тяга на одной ноге (4), нордические сгибания — негатив (5) |
| `lunge` | статический сплит-присед (2), зашагивания на возвышение (3), боковые выпады (3), «конькобежец» (5) |
| `core` | «мёртвый жук» (1), птица-собака (1), планка на прямых руках (2, без контакта локтей), подъёмы коленей в висе (3), «лодочка» (4), подъёмы ног в висе (4), уголок (5) |

## Промпт для ИИ

Скопируйте целиком, в конце допишите, что нужно:

```text
Ты помогаешь наполнить каталог упражнений приложения Fitnote — офлайн-тренера для
уличной площадки и дома (функциональные тренировки с собственным весом, турник,
брусья, петли, резинки, иногда гиря или гантели).

Верни ТОЛЬКО JSON вида {"exercises": [ ... ]} без пояснений. Каждое упражнение —
объект с полями:
- id: латиница в нижнем регистре и дефисы, например "air-squats"; для этих
  упражнений используй ровно такие id: air-squats (Air Squats), single-leg-rdl
  (Single-Leg Romanian Deadlift), hanging-knee-raises (Hanging Knee Raises); не повторяй
  существующие id: strict-pull-ups, parallel-bar-dips, australian-pull-ups,
  floor-push-ups, bulgarian-split-squat, single-leg-glute-bridge, side-plank,
  dead-hang, pallof-press, romanian-deadlift, band-row, reverse-lunges, pike-push-ups;
- pattern: push_h | pull_h | push_v | pull_v | squat | hinge | lunge | core;
- family: семейство лестницы прогрессий. Существующие: push_horizontal,
  push_vertical, pull_horizontal, pull_vertical, legs_knee (присед и выпады),
  hinge, core_lateral, core_antirotation, hang. Новое — только если упражнения
  не заменяют друг друга;
- rank: 1..5 (1 "--", 2 "-", 3 "Base", 4 "+", 5 "++"). Опорные: отжимания от пола,
  обратные выпады, румынская тяга, строгие подтягивания, австралийские
  подтягивания, отжимания «домиком», боковая планка, жим Паллофа = 3;
  брусья, болгарские выпады = 4; тяга резинки, ягодичный мост на одной ноге,
  вис на турнике = 2;
- metric: "reps" или "seconds"; isPaired: true, если выполняется на каждую сторону;
- environments: ["outdoor"] и/или ["home"];
- equipment: из bodyweight, pullup_bars, suspension, bands, weights (достаточно
  любого из списка; bodyweight = ничего не нужно);
- posture: из standing, hands_only, floor_contact (floor_contact = локти, спина
  или колени на земле; такие исключаются на мокрой площадке);
- stability: bilateral | unilateral | unstable;
- targetMuscles и antagonistMuscles: теги из lats, biceps, chest, triceps,
  front_delts, rear_delts, upper_back, quads, glutes, hamstrings, hip_flexors,
  obliques, core, lower_back, forearms, spine_decompression, shoulder_press;
- svgKey: похожая картинка из pullups, dips, australian_pullups, pushups,
  bulgarian_split_squat, glute_bridge, side_plank, dead_hang, pallof_press,
  romanian_deadlift, band_row, reverse_lunges, pike_pushups, иначе generic_strength;
- defaultMax: {"low", "medium", "high"} — реалистичный максимум в одном подходе
  для начинающего, среднего и продвинутого любителя (для seconds — секунды);
- teenAllowed: false — только если упражнение опасно для подростка;
- ladder: {"minus1": id, "plus1": id} — соседи на ступень легче и тяжелее из того
  же family (существующие или из этого же ответа), если они очевидны;
- text.ru: {"name": английское общепринятое название, "cue": одно короткое
  предложение по технике на русском (до 140 символов), "details": 3–5 предложений
  на русском: исходное положение, движение с дыханием, частая ошибка};
  text.en: то же на английском; text.tr: то же на турецком с принятой
  спортивной терминологией (Barfiks, Şınav и т. д.).

Правила: только суставно-безопасные варианты (никаких отжиманий от скамьи за
спиной, тяг за голову, кипинга, нагрузки на шею). Не выдумывай экзотику —
упражнения должны быть известны тренерам и выполнимы на обычной площадке или дома.

Задание: <например: «закрой паттерн pull_v на ступенях 1, 2, 4, 5 для площадки
и дома» или список названий>.
```
