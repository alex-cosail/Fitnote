# Дополнение №3 к SPEC_FITNOTE_V3.md
**Тема:** Кнопка «Освежить тренировку (Вариация)» и умное добавление новых упражнений (с YouTube / через ИИ) с автоматической разметкой по паттернам и лестнице прогрессий.

---

## 1. Кнопка «Освежить тренировку» (`✨ Вариация` на карточке воркаута)

### Цель
Позволить пользователю в 1 клик получить свежий состав упражнений на базе существующей тренировки (например, `Тренировка А`), сохранив её целевой профиль, время, акценты и ограничения (`NO TOUCH`).

### Требования к реализации
1. **Локальный генератор вариаций (Zero-Latency Engine):**
   - Добавить кнопку **`✨ Вариация`** на экран просмотра воркаута рядом с кнопкой запуска.
   - По нажатию алгоритм проходит по слотам текущей тренировки (`slot[i]`), сохраняет исходный `pattern` и целевую интенсивность, но подбирает **альтернативное упражнение** из того же паттерна (и смежного ранга сложности `±1`), отфильтрованное по доступному инвентарю и `cleanFloor`.
   - Целевое число повторений пересчитывается автоматически по `checkup_max` нового упражнения.
   - Пользователь может сразу запустить полученную вариацию или сохранить её как `Тренировка А · Вариант 2`.
2. **ИИ-режим «Переосмыслить через ИИ»:**
   - Опция внутри меню вариаций, формирующая готовый промпт с текущей тренировкой и пожеланием пользователя (например: *«сделай акцент на взрывную скорость»* или *«замени все упражнения на работу с резинкой»*) для генерации нового JSON-плана.

## 2. Умное добавление упражнений (с YouTube / через ИИ) в каталог (`CustomExerciseImporter.tsx`)

### Цель
Дать пользователю возможность добавить любое понравившееся упражнение (увиденное на YouTube или у тренера) так, чтобы оно автоматически получило разметку по 8 паттернам, встроилось в 5-ступенчатую лестницу прогрессий и сразу участвовало в автогенерации тренировок.

### Требования к реализации
1. **Точка входа:** кнопка **`+ Новое упражнение (YouTube / ИИ)`** в каталоге и в модалке замены упражнения (`⇄`).
2. **Поля ввода:**
   - Название упражнения (или краткое описание техники);
   - Ссылка на YouTube-видео / таймкод (опционально — сохраняется в поле `videoUrl` карточки упражнения для быстрого просмотра техники на площадке).
3. **Автоматическая классификация (2 режима на выбор):**
   - **Через ИИ (AI Auto-Tagging / JSON-мост):** ИИ возвращает заполненный объект `Exercise` со всеми системными полями: `pattern`, `difficultyRank (1..5)`, `equipment`, `postureTags` (учёт `NO TOUCH`), `stabilityType`, `ladder` (связь с соседними ступенями в каталоге) и расчётный `checkup_max` на основе смежных упражнений пользователя.
   - **Быстрая ручная разметка (Оффлайн-фолбэк в 3 клика):** визуальный выбор паттерна (из 8 иконок), тегов инвентаря/пола и положения на шкале сложности (`Старт` → `Мастер`) относительно базового упражнения этого паттерна.
4. **Интеграция в генератор:** пользовательские упражнения (`isCustom: true`) хранятся в профиле и равноправно участвуют в конструкторе (`Workout Studio`), кнопке `✨ Вариация` и предтренировочной замене `⇄`.
